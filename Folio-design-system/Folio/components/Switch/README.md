# Switch
An immediate on/off setting (preferences only — never for record data that needs saving).

**Consumer provides:** `label`, `checked`/`defaultChecked`, `onChange`, `disabled`. `showState` (default true) prints On/Off.

## Rules
- Takes effect immediately; if a Save button is needed, use a `Checkbox` instead.
- On = `primary` track with a check in the thumb, plus the word "On".

Naming: `Switch / Off`, `Switch / On`, `Switch / Focus`, `Switch / Disabled`.
