# Add a child
A short, single-column form in a page (not a dialog) — the first thing a new household does.

1. Name (required), date of birth (optional), A.C.E. level.
2. Continue to **Assign subjects** (next pattern). Steps are shown as "Step 1 of 3" text, not a progress gimmick.
3. Save creates the child; a toast confirms; the household dashboard shows the new ChildSummaryCard.

Components: `PageHeader`, `Card`, `Field`, `TextInput`, `DateInput`, `Select`, `Button`. Width: `form-max`.
