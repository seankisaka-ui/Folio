# Log progress
The most frequent task. Reachable from a PaceCard ("Log progress"), the sidebar, bottom nav, or the assistant.

- Context is pre-filled and read-only (child, subject, PACE) when launched from a card; selectable when launched globally.
- Enter a page range (From / To) **or** mark a stage complete (Checkup, Self Test). Date defaults to today.
- Save → toast "Progress saved for Sarah" with Undo; the PaceCard updates "Progress updated today".
