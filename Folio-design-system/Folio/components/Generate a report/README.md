# Generate or preview a report
Choose child(ren), period and contents, then preview the report exactly as it will print. Reports use Atkinson Hyperlegible Next for everything except the title (Bricolage), black on white, `reading-max` width, no colour-only meaning — they must survive black-and-white printing.

Actions: Download PDF (primary), Print (outline). AI-assisted entries keep their tag in the report.
