# AssistantComposer
Natural-language entry for the assistant, with example prompts. The assistant **proposes**; it never saves.

**Consumer provides:** `value`, `onChange`, `onSubmit`, `loading`, optional `prompts`, `placeholder`.

## Rules
- Lives on `ai-surface` with `ai-border` and the `sparkles` icon, so AI territory is always recognisable.
- The persistent note "Nothing is saved until you confirm" is part of the component.
- Example prompts use the household's real names and current PACE numbers.
- The manual form is always one click away; the assistant is a shortcut, not a gate.
