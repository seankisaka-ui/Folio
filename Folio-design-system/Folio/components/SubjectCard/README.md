# SubjectCard
A subject assigned to a child with its current PACE, page progress and status.

**Consumer provides:** `subject`, `pace`, `progress`/`pagesDone`/`pagesTotal`, `status` (StatusBadge value), `updated`, optional `onClick` (becomes an InteractiveCard), `selected`.

States: Active (in progress) · Ready for test · Complete (passed) · Not started / unassigned · Selected.
