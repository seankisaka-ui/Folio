# Confirm advancement to the next PACE
Advancing is always an explicit, confirmed step — never automatic after a score.

- Trigger: "Advance to PACE 1049" on a passed PaceCard.
- ConfirmDialog summary: Completed PACE 1048 · 92% → Next PACE 1049 · starts today. The next number is pre-filled but editable ("Change next PACE") for households that skip or reorder.
- After saving: PACE 1048 moves to Academic history (permanent record); the card resets to PACE 1049, stage "Pages", 0 pages.
