# SidebarSection
A labelled group of NavItems. The heading is an `h2` in `text-overline` (13px, uppercase, `sidebar-heading`, 4.83:1) and names the list for screen readers.

**Consumer provides:** `title`, NavItem children.

Rules: two sections maximum ("Main menu", "Help"); `space-5` between sections; headings hide when the sidebar collapses.
