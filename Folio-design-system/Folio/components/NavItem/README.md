# NavItem
One sidebar destination: 22px icon + always-visible text label at 44px tall.

**Consumer provides:** `icon`, `label`, `href`, `current`, optional `count` (new items, announced as "2 new"), `disabled`, `collapsed`.

States: Default (`sidebar-fg-muted`) · Hover (`sidebar-item-hover`) · Focus (`focus-ring-inverse`) · Selected (`sidebar-item-selected` + indicator + bold) · Disabled (`forest-400`, `aria-disabled`).

Naming: `Navigation / Sidebar Item / Default`, `… / Hover`, `… / Focus`, `… / Selected`, `… / Disabled`.
