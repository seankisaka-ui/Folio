# Icons

The 47 Lucide outline icons (ISC licence) Folio uses, as single-ink SVGs: 24px grid, 2px stroke, ink `#21483E` (forest-800). These files are for reference and design tools — `<img>` can't inherit colour. In product code use the `Icon` component (`<Icon name="clipboard-check" />`), which renders the same paths inline with `currentColor`. The meaning of each icon is fixed in the Iconography section.
