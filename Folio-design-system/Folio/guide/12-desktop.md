# 12. Desktop examples

Validation examples built only from this system (cards in the **Desktop examples** group, laid out at 1280px):

1. **Household dashboard** — `text-display` greeting, three decision stats, children grid, "Needs attention" list and recent activity. No charts.
2. **Child profile** — avatar + `text-h1` name, ChildSwitcher in the header, Tabs, one PaceCard per subject with exactly one next action each.
3. **Progress-entry form** — form at `form-max` with an inline validation error, beside the live PaceCard for verification.
4. **Test-score confirmation** — ConfirmDialog over the profile summarising child, subject, PACE, score, pass mark and date.
5. **AI action confirmation** — composer + interpreted preview awaiting "Save to record", beside the clarification state.

What they prove: the sidebar/workspace contrast, the Bricolage/Atkinson pairing, restrained green, comfortable density, one primary action per view, and that every status reads without colour.
